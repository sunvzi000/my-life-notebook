# 自我认知提升

> 认识自己是一辈子的事。这里记录你对"我是谁"的探索。

## 这个模块怎么用

### 你可以记录
- **性格发现** — "我发现我在___情况下会___"
- **情绪模式** — "我容易在___时候感到___"
- **边界觉察** — "我意识到我不喜欢___"
- **价值观梳理** — "对我来说最重要的是___"
- **行为模式** — "我总是___，然后___"
- **自我对话** — 你跟自己说的那些话

### WorkBuddy会帮你
- 从你的碎碎念中提炼出**反复出现的模式**
- 在"我的观察"模块记录我对你的长期认知
- 当你的行为和你的目标不一致时，温和地提醒你
- 帮你发现你自己没注意到的优点
