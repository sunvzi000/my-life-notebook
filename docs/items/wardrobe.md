## 一、分类与编号规则

| 前缀 | 含义 | 说明 |
|------|------|------|
| B | 贴身打底 | Base Layer，含长袖/短袖/无袖 |
| C | 冬季厚外套 | Coat，羽绒/呢绒/厚卫衣外套等 |
| SC | 春秋薄外套 | Spring Coat，薄款西装/衬衫外套等 |
| SW | 冬季厚毛衣 | Sweater，羊毛/厚实款 |

| SS | 短袖上衣 | Short Sleeve |
| LS | 长袖上衣 | Long Sleeve（非毛衣/非打底） |
| KC | 开衫/罩衫 | Cardigan / Cover-up |
| T | 可单穿打底 | Top（非贴身层） |
| W | 冬季加绒裤 | Winter Pants |
| S | 春秋单裤 | Spring Pants |
| SH | 短裤/中裤 | Shorts |
| SK | 半裙 | Skirt |
| DR | 连衣裙 | Dress |
| ST | 套装 | Suit/Set |
| TS | 可拆分两件套 | Two-piece Set |
| U | 多功能单品 | Versatile |
| H | 手工自制 | Handmade |
| M | 极寒备用/纪念 | Memorial |
| WK | 工作服 | Work |
| R | 浴袍/家居外套 | Robe |
| SOC | 袜子 | Socks |
| SI | 运动内衣 | Sports Inner |
| SL | 瑜伽裤/运动长裤 | Sports Leggings |

### 命名规则（四部分）
**1颜色 + 2标志性识别特色 + 3材质/长短 + 4名字**

示例：
- AT-01 白色小翻领蕾丝边仿开衫针织衫
- SW-19 粉色四朵花织花按扣开衫厚重毛衣
- H-02 天蓝色两股马海毛短款可可背心

> 第4部分"名字"：特定名称（如"可可背心"）优先保留；没有的用品类名。
