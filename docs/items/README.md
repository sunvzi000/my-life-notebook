## 购物决策清单
买东西前，问自己这5个问题：

1. **我现在需要它吗？**（不是"以后可能需要"）
2. **家里有类似的东西能替代吗？**
3. **它放哪里？**（如果没有确定的位置，别买）
4. **我会用它超过10次吗？**
5. **3天后我还想要吗？**（加入购物车，等3天再决定）

如果5个问题有2个以上"否"，就别买。
忍住了，记到看板的"消费反思"里，看着省下的钱增长。

## 断舍离计划

### 低精力断舍离法（每次15分钟）
你精力有限，不要试图一天收拾完。用这个方法：

1. **选一个巴掌大的区域**（一个抽屉、一个角落）
2. **设15分钟闹钟**
3. **只做3件事**：扔垃圾 → 挑出不要的 → 剩下的摆整齐
4. **闹钟响了就停**，即使没弄完
5. **拍一张before/after照片**，给自己成就感

> 每天收拾15分钟，一个月就是7.5小时，比一次收拾3小时然后躺平有效得多。
