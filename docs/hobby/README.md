## ⚠️ 手部健康

**重要：** 之前钩针玩到手抽筋，早上要用手指头掰开才能动——这是重复性劳损。

**保护规则：**
1. 每次钩针不超过30分钟，强制休息
2. 休息时做手指拉伸
3. 手不舒服立刻停，不要硬撑
4. 棒针比钩针对手更友好，可以交替进行

> 手工是疗愈，不是惩罚。手坏了就什么都做不了了。
