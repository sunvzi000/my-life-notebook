# 每日计划与复盘

> 低精力不是缺陷，是身体在保护你。每天完成1件正事就算赢。

## 这个模块怎么用

### 每日计划
- 每天最多安排 **3件正事 + 2件小事**
- 按"精力时段"分配任务，而不是按时间
- 允许自己只完成1件，其余顺延，不内疚

### 每日复盘（建议睡前10分钟）
在HTML看板的"日记与复盘"页面完成：
1. **一句话日记** — 今天最想记住的瞬间
2. **精力打分** — 电量满 / 一般 / 很低
3. **消费反思** — 今天有没有乱花钱
4. **明日小事** — 明天想做到的一件小事就够了

### WorkBuddy的复盘提问
每天你打开看板做复盘时，我会根据你的打卡情况问你：
- 今天有没有做面膜？什么功能的？
  - 夏天早上不建议美白面膜（熊果苷/VC遇阳光可能反黑）
  - 清洁面膜一周1-2次，做完要补水
  - 补水面膜可以天天做
- 今天睡眠怎么样？几点醒的？
- 今天精力如何？有没有勉强自己？
- 今天有没有想买但忍住的东西？

## 文件说明
- `templates/` — 每日计划模板和复盘模板
- `2026-07.md` — 按月归档的复盘记录（我会帮你整理碎碎念生成）

## 精力时段分配原则

| 时段 | 精力水平 | 适合做什么 | 不适合做什么 |
|------|---------|-----------|-------------|
| 09:00-11:00 | 高 | 思考、决策、重要工作 | 刷手机、闲聊 |
| 14:00-16:00 | 中 | 整理、打卡、回复、家务 | 重要决策、创造性工作 |
| 16:00后 | 低 | 15分钟微任务、陪伴宝宝、休息 | 强迫自己做大事 |
| 晚间 | 不确定 | 记录、放松、手工（如钩毯子） | 刷手机到凌晨 |

## 低精力日的自我对话
> "我今天只做了一件事，但那已经足够了。"
> "洗了衣服就是胜利，不需要把整个家都收拾好。"
> "休息不是偷懒，是给明天的自己充电。"
