# 家务管理

> 低精力人的家务哲学：不做超人，做15分钟微任务大师。

## 核心原则
1. **家务不是项目，是习惯** — 每天做一点，比一周做大扫除好
2. **15分钟是一个完整单位** — 不要安排超过15分钟的单项家务
3. **完成比完美重要** — 洗了衣服没晾比没洗好
4. **允许"及格线"** — 家不需要一尘不染，"过得去"就行

## 家务分类

### 🟢 5分钟微任务（随时可做）
- 把桌面东西归位
- 把衣服丢进洗衣机
- 倒一袋垃圾
- 擦一张桌子
- 把碗放进水槽泡着

### 🟡 15分钟小任务（精力中等时做）
- 晾衣服
- 收拾一个台面
- 拖一个房间
- 整理一个抽屉
- 给宝宝整理玩具

### 🔴 30分钟中任务（精力好时做，一周1-2次）
- 完整做一次饭
- 大件衣物洗涤
- 卫生间深度清洁
- 厨房灶台清洁

## 每日最低家务线
> 这是"及格线"，完成这些就算家里"过得去"了

- [ ] 衣服丢洗衣机（按一下按钮的事）
- [ ] 餐桌清空（能放碗就行）
- [ ] 垃圾袋扎好放门口
- [ ] 宝宝玩具归拢到一个区域（不用分类，堆一起就行）

**完成以上4项 = 家务及格。多做都是加分。**

## 每周家务轮盘
> 不用全做，精力好时挑1-2项

| 周一 | 周二 | 周三 | 周四 | 周五 | 周六 | 周日 |
|------|------|------|------|------|------|------|
| 洗衣 | 擦灰 | 拖地 | 收纳 | 洗衣 | 大任务 | 休息日 |

## 家务 delegation 清单
> 哪些事可以让别人帮忙 / 用工具替代

- 洗碗机 → 如果有，就用
- 扫地机器人 → 如果有，每天开一次
- 另一半 → 分配明确任务（不是"你帮我做"而是"这是你的事"）
- 宝宝 → 3岁+可以帮忙收玩具、拿东西（培养习惯）

## 当你"想收拾但半小时就累了"时
1. **正常** — 你的精力就是这么多，不是你的错
2. **记录你做了什么** — 哪怕只洗了衣服，也记一笔
3. **休息** — 躺下，不要有负罪感
4. **剩下的明天做** — 家务不会跑掉

## 季节性家务
| 季节 | 重点 | 时间 |
|------|------|------|
| 春 | 换季收纳、除湿 | 3-4月 |
| 夏 | 空调清洁、防蚊 | 5-6月 |
| 秋 | 换季收纳、晒被子 | 9-10月 |
| 冬 | 取暖设备、加湿器 | 11-12月 |
