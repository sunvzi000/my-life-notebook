### 低精力社交原则
1. **不需要维系所有关系** — 精力有限，留给重要的人
2. **一条微信也是联系** — 不一定见面，偶尔问候就够
3. **拒绝是能力** — "我今天状态不太好"是完全可以的理由
4. **社交后留恢复时间** — 社交消耗你精力，之后需要独处充电
