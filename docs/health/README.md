# 健康管理

> 睡眠、用药、护肤、饮食。你不是要"变健康"，是要"了解自己的身体节奏"。

## 睡眠管理

### 我的睡眠模式
- 入睡时间：通常___
- 半夜醒来：凌晨2-3点（频繁）
- 醒后行为：以前刷手机 → 现在尝试做手工/看书
- 总睡眠：通常___小时
- 咖啡因敏感：是，下午2点后不喝

### 睡眠改善策略
1. **下午2点后不碰咖啡因** — 你已经验证过喝了会失眠
2. **醒了不要刷手机** — 蓝光会让彻底清醒，做手工/看纸质书更好
3. **不要强迫自己睡** — 躺着睡不着比起来做点事更焦虑
4. **宝宝哄睡后如果清醒，做放松的事** — 你发现钩毯子到困了再睡，反而睡得好
5. **早上固定时间起床** — 即使昨晚没睡好，也固定起床，帮助调节节律
6. **睡前听小说定时10分钟** — 用睡眠耳机听小说，定时10分钟自动停止，帮助入睡

### 常见药物成分速查
| 药品 | 主要成分 | 注意事项 |
|------|---------|---------|
| 泰诺/白加黑/999感冒灵 | 对乙酰氨基酚 | 一天总量不超过2g，别叠加 |
| 布洛芬（芬必得） | 布洛芬 | 饭后吃，伤胃，别和阿司匹林同服 |
| 开瑞坦 | 氯雷他定 | 别和西替利嗪叠加 |
| 头孢类 | 头孢 | 吃药+停药7天内绝对不能喝酒 |
| 阿莫西林 | 阿莫西林（青霉素类） | 确认不过敏 |
| 白加黑/新康泰克 | 伪麻黄碱 | 高血压、心脏病慎用 |

> ⚠️ 这只是常见提醒，具体用药请遵医嘱。

## 护肤管理

### 面膜使用指南
| 类型 | 频率 | 注意事项 |
|------|------|---------|
| 补水 | 可天天 | 最安全，随时可用 |
| 美白 | 每周2-3次 | 含熊果苷/VC，**白天用后必须防晒**，建议晚上用 |
| 修护 | 按需 | 皮肤敏感时用 |
| 清洁 | 每周1-2次 | 做完必须补水 |

### 季节护肤重点
| 季节 | 重点 | 注意 |
|------|------|------|
| 春 | 防敏、保湿 | 花粉季注意 |
| 夏 | 防晒、控油 | **防晒比美白重要**，早上不适合美白 |
| 秋 | 保湿、修护 | 换季容易敏感 |
| 冬 | 滋润、防干 | 室内加湿 |
