# 我的生活管理系统 · 使用说明

> 这不是一个要求你"自律"的系统，是一个**适应你低精力**的系统。
> 不需要每天填满，能做多少做多少。

## 系统组成

```
personal-system/
├── index.html              ← 可视化看板（手机浏览器打开）
├── README.md               ← 你正在看的这个文件
├── docs/                   ← 所有文档记录
│   ├── daily-review/       ← 每日计划与复盘
│   ├── self-cognition/     ← 自我认知提升
│   ├── my-observations/    ← WorkBuddy对你的观察
│   ├── items/              ← 物品管理（断舍离+购物反思）
│   ├── housework/          ← 家务管理（低精力友好）
│   ├── baby/               ← 宝宝成长档案（3岁+）
│   ├── health/             ← 健康管理（睡眠+用药+护肤）
│   ├── period/             ← 经期管理（自动提醒）
│   ├── knowledge/          ← 知识迭代
│   ├── annual-diary/       ← 年度一句话日记
│   ├── social/             ← 人情世故
│   └── work/               ← 工作手帐
├── templates/              ← 模板
│   ├── daily-plan-template.md
│   └── daily-review-template.md
└── sop/                    ← 场景SOP（触发词激活）
    ├── morning.md          ← "早上好" → 今日任务清单
    ├── home.md             ← "到家了" → 回家SOP
    ├── baby-swim.md        ← "宝宝游泳" → 装备清单
    ├── low-energy.md       ← "今天很累" → 低精力预案
    ├── period-prep.md      ← 自动提前5天触发
    └── medication-check.md ← "吃了XX药" → 成分查询
```

## ⭐ 核心使用方式：跟我说就行了

**你说 = 我帮你记。不需要自己动手点看板。**

> 比如你说"喝了水"，我就帮你打卡喝水。
> 你说"凌晨3点又醒了"，我就记录睡眠中断。
> 你说"宝宝今天自己穿了鞋"，我就记到宝宝档案。
> 你说"做了美白面膜"，我就记面膜打卡+提醒防晒。

看板（`index.html`）是给你看的，操作主要靠跟我说。

## 日常使用流程

### 🌅 早上
- 对我说"**早上好**"
- → 我给你今日任务清单 + 精力建议 + 今日提醒
- 有什么想做的任务直接说"今天要做XXX"

### ☀️ 白天
- **随便碎碎念**，想到什么说什么
- 每句话我都会识别并自动记录
- 比如"刚才喝了水""吃了维生素""带宝宝去公园了"

### 🏠 到家
- 对我说"**到家了**"
- → 我给你回家SOP

### 🌙 睡前
- 对我说"**复盘**"或"**今天过完了**"
- → 我会问你：面膜？精力？消费？宝宝？明天一件事？
- 你回答，我帮你整理成复盘记录
- 顺便说"X点睡的"，我记录睡眠

## 和WorkBuddy配合的方式

### ⭐ 核心：你说什么我做什么

你说"喝了水" → 我帮你打卡喝水 ✅
你说"做了面膜" → 我记面膜打卡 + 问什么功能 + 给护肤建议 ✅
你说"凌晨3点醒了" → 我记睡眠中断 + 更新观察档案 ✅
你说"宝宝今天XXX" → 我记到宝宝成长档案 ✅
你说"买了XXX花了XX元" → 我记消费 + 问是需要的还是想要的 ✅
你说"我吃了XX药" → 我记用药 + 查成分 + 检查冲突 ✅
你说"今天心情很好" → 我记心情 😊 ✅
你说"来例假了" → 我记经期开始 + 更新周期预测 ✅

**一切都在对话里完成，不需要切换页面。**

### 场景触发
直接说触发词，我返回对应SOP：
| 你说 | 我返回 |
|------|--------|
| 早上好 | 今日任务清单+精力建议 |
| 到家了 | 回家SOP |
| 带宝宝去游泳 | 装备清单 |
| 今天很累 | 低精力预案 |

### 复盘提问
每天你做复盘时，我会根据你今天的打卡和碎碎念问你：
- 今天做面膜了吗？什么功能？（+护肤建议）
- 今天睡眠怎么样？
- 今天精力如何？
- 今天有没有忍住没买的东西？
- 今天宝宝有什么趣事？

## 重要：这是低精力系统

### 设计原则
1. **每天1件事就是胜利** — 不要求你做完所有
2. **15分钟是一个单位** — 任何任务都能拆成15分钟
3. **允许空白** — 没记录的日子不内疚
4. **看板数据存在本地** — 隐私安全，不用担心

### 如果几天没记
- 没关系，回来继续就行
- 不需要补记
- 重要的是"现在开始"，不是"完美记录"

### 如果想改系统
- 随时告诉我，我们一起调整
- 系统是为你服务的，不是你为系统服务的
- 不合适的部分砍掉，好用的部分加强

## 数据说明
- **你说的话 = 我直接记录**到Markdown文档中（永久保存）
- 看板数据也存浏览器本地（localStorage），方便你打开看
- 重要内容都会沉淀到文档里，换设备也不丢
- `data.json` 是数据中转文件，我通过修改它来同步你的打卡数据
- `sop/trigger-mapping.md` 是完整的对话触发映射表，你可以查看所有我能识别的关键词

## 最后

这个系统不是要让你变成一个"高效自律"的人。
是让你在低精力的日子里，也能：
- 知道自己今天该做什么（哪怕只有一件事）
- 记住生活里的小确幸（一句话日记）
- 不被购物冲动控制（消费反思）
- 被温柔提醒（经期、用药、护肤）
- 有一个地方存放对自己的认知

**你不需要变好。你只需要被理解。**
