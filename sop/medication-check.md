# 💊 用药记录与成分查询

> 触发：你告诉WorkBuddy"我今天吃了XXX药" / "这个药能吃吗"

## WorkBuddy会做的

### 当你报告吃了药
1. 记录药名、日期到看板"用药记录"
2. 查询药品主要成分
3. 对比你已记录的用药历史，检查是否有冲突
4. 返回提醒

### 当你问"这个药能吃吗"
1. 查询该药成分
2. 对比你正在吃的药
3. 检查你的过敏和禁忌
4. 给出建议（能吃/不能吃/需间隔多久）

## 常见药物冲突速查

| 药A | 药B | 冲突情况 |
|-----|-----|---------|
| 对乙酰氨基酚类（泰诺/白加黑/999感冒灵） | 同类感冒药 | 对乙酰氨基酚超标伤肝，一天总量<2g |
| 布洛芬 | 阿司匹林 | 都是NSAID，叠加伤胃出血风险 |
| 布洛芬 | 酒精 | 伤胃出血风险 |
| 头孢类 | 酒精 | 双硫仑反应，可能致命 |
| 氯雷他定 | 西替利嗪 | 都是抗组胺药，不要叠加 |
| 伪麻黄碱（感冒药） | 降压药 | 可能影响血压 |
| 中成药 | 西药 | 至少间隔30分钟-1小时服用 |
