# 🔋 低精力日预案

> 触发条件：你告诉WorkBuddy"今天很累" / "没精力" / "什么都不想干"
> 或：昨晚睡眠<5小时

## WorkBuddy收到低精力信号后，会：

### 1. 调整今日待办
- 删除所有非必要任务
- 只保留1件必须做的事（如果有的话）
- 告诉你："今天只做这一件事就够了"

### 2. 推荐最低家务线
- 衣服丢洗衣机
- 餐桌能放碗就行
- 其余全部跳过

### 3. 推荐低消耗活动
- 躺着听播客/有声书
- 和宝宝一起看动画片
- 做手工（坐着不动脑子）
- 发呆也是可以的

### 4. 饮食建议
- 点外卖可以，不要自责
- 或者简单吃：面包+牛奶+水果
- 不要在低精力时做复杂的饭

### 5. 情绪保护
- 告诉你："低精力不是你的错"
- 告诉你："今天的目标是'活着'，不是'过好'"
- 不要在低精力时做任何决定（尤其是购物）

---

## 低精力日的"可以"和"不可以"

| 可以 | 不可以 |
|------|--------|
| 躺着 | 强迫自己大扫除 |
| 点外卖 | 做复杂的饭 |
| 看剧 | 刷购物软件 |
| 让宝宝看动画片 | 负疚"不是好妈妈" |
| 不回非紧急消息 | 在社交媒体比较 |
| 做手工 | 深夜刷手机 |
| 什么都不做 | 责怪自己"又浪费了一天" |

## 低精力日的购物警告
⚠️ 低精力时判断力下降，**绝对不要下单任何东西**
- 如果想买，加入购物车，等3天
- 凌晨睡不着时更不能买（你容易在此时冲动消费）

## 如果连续3天低精力
- 可能不是"状态不好"，是需要看医生
- 检查：睡眠、铁蛋白、甲状腺、维生素D
- 不要硬扛，身体在发出信号

## 给低精力日自己的话
> "今天我什么都不做，这也是一种选择。"
> "我的价值不取决于今天完成了多少事。"
> "休息是为了明天能有一点点精力。"
> "宝宝不需要一个完美的妈妈，需要一个真实的妈妈。"
