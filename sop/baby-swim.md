# 🏊 带宝宝游泳清单

> 触发词：对WorkBuddy说"带宝宝去游泳" / "宝宝游泳要带什么"

## 出发前清单（提前30分钟准备）

### 必带物品
- [ ] 泳衣（宝宝+你的）
- [ ] 泳镜（宝宝专用）
- [ ] 泳帽
- [ ] 浴巾 × 2（宝宝+你）
- [ ] 浴袍/浴裙（方便换）
- [ ] 拖鞋（宝宝+你）

### 洗护用品
- [ ] 沐浴露（宝宝专用，温和型）
- [ ] 洗发水
- [ ] 护肤乳/身体乳（游完泳皮肤会干）
- [ ] 棉签（清理耳朵）
- [ ] 梳子

### 换洗衣物
- [ ] 宝宝干净内衣 × 1套
- [ ] 宝宝外衣 × 1套
- [ ] 你的干净衣物 × 1套
- [ ] 内衣裤（宝宝+你）

### 其他
- [ ] 防水尿不湿（如宝宝还需穿）
- [ ] 饮用水/水壶
- [ ] 小零食（游完泳会饿）
- [ ] 干湿分离袋（装湿泳衣）
- [ ] 防滑袜（如场地需要）

### 季节性
- ☀️ 夏季：防晒霜、遮阳帽
- ❄️ 冬季：厚外套、帽子（出水后保暖）

## 游泳后流程
1. 先冲洗宝宝（温水，冲掉池水中的氯）
2. 涂身体乳（防止皮肤干）
3. 换干净衣服
4. 喝温水补充水分
5. 吃点小零食
6. 回家后注意观察宝宝有没有着凉

## 注意事项
- 游泳前1小时不要让宝宝吃太饱
- 游泳时间：3岁+建议30-45分钟
- 水温适宜：32-34°C
- 如果宝宝有任何不适，立刻停止
- 游完泳当天晚上可能睡得好（体力消耗大）

- 你可以边收拾边对照打勾
- 回来后我会问你"宝宝今天游得怎么样"记录到宝宝档案
