# 🏠 回家SOP

> 触发词：对WorkBuddy说"到家了" / "我回来了"

## WorkBuddy收到"到家了"后，会返回：

### 1. 换鞋换衣（2分钟）
- 换拖鞋
- 外套挂好（不要丢沙发上）
- 包包放固定位置

### 2. 洗手洗脸（1分钟）
- 用洗手液洗手
- 洗把脸（洗掉一天的疲惫感）

### 3. 放下手机（关键！）
- 把手机放在充电器上
- 设定"无手机时间"至少30分钟
- 这是你和宝宝的高质量时间

### 4. 宝宝时间（20-30分钟）
- 蹲下来和宝宝平视打招呼
- 问"今天开心吗？"（不要问"吃了什么/学了什么"）
- 一起做一件事：看书/玩玩具/聊天
- 全神贯注，不看手机

### 5. 最低家务线（5分钟）
- [ ] 衣服丢洗衣机（按一下按钮）
- [ ] 餐桌清空
- [ ] 垃圾袋扎好放门口
> 完成这3项 = 家务及格

### 6. 晚餐（如需准备）
- 简单为主，不要给自己压力
- 一荤一素一汤就很好
- 实在累就点外卖/吃速食，不内疚

### 7. 晚间放松
- 不要安排任何"正事"
- 可以做手工（钩毯子）
- 可以看剧/看书
- 22:30开始准备睡觉

---

## 如果今天精力很低
- 跳过第4步以外所有步骤
- 直接躺下休息
- 家务明天再说
- 跟宝宝说"妈妈今天有点累，我们躺着讲故事好不好？"

## 如果带了东西回来
- 立刻归位，不要"先放着待会收"
- "待会"通常意味着"永远"
